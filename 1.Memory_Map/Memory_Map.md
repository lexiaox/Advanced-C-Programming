# Lab 1：内存地图观察器

## 1. 目标

通过打印地址和观察生命周期，真正理解：

- 栈变量
- 堆变量
- 全局变量
- `static` 变量
- 函数参数

## 2. 你要完成的功能

- 定义一个全局变量
- 定义一个 `static` 全局变量
- 在函数里定义一个局部变量
- 在函数里定义一个 `static` 局部变量
- 用 `malloc` 申请一块堆内存
- 分别打印它们的地址

## 3. 必做任务

1. 写一个函数，打印局部变量和参数地址。
2. 写一个函数，返回一块堆内存地址。
3. 故意写一个“返回局部变量地址”的错误函数，观察警告，再修正。
4. 画一张你自己的内存草图。

## 4. 观察重点

- 同一次运行里，哪些地址彼此接近
- 不同函数调用时，局部变量地址有没有规律
- `static` 局部变量和普通局部变量的区别
- 指针变量本身地址和它指向地址的区别

## 5. 验收标准

- 能清楚解释每个变量的生命周期
- 能解释为什么返回局部变量地址是错的
- 能解释“指针变量”和“指向对象”不是一回事
